# Документация развертывания

## Обзор

Данный документ описывает процесс работы с драйвером дисплея ST7735S для различных платформ.ы

## Файлы ввода-вывода (stm32f4_io)

### Назначение

Файлы `stm32f4_io.c` и `stm32f4_io.h` предоставляют низкоуровневые функции для работы с:
- SPI интерфейсом для общения с дисплеем ST7735S
- Управлением пинами (CS, DC, RESET)
- Таймерными задержками

### Ключевые функции

#### Инициализация SPI
```c
int32_t STM32F4_IO_SPI_Init(void)
```
Инициализирует SPI1.

#### Запись данных в регистр
```c
int32_t STM32F4_IO_SPI_WriteDataReg(uint8_t reg, uint8_t *pdata, uint32_t length)
```
Отправляет команду (регистр) и данные через SPI.

#### Отправка данных
```c
int32_t STM32F4_IO_SPI_SendData(uint8_t *pdata, uint32_t length)
```
Отправляет только данные через SPI.

#### Задержка
```c
int32_t STM32F4_IO_Delay_Func(uint32_t delay_ms)
```
Реализует задержку в миллисекундах.

### Конфигурация пинов

В файле `stm32f4_io.h` определены пины для управления дисплеем:
- RESET: PD2
- Chip Select (CS): PD1
- Data/Command (DC): PD3

## Сборка проекта

### Требования
- Компилятор ARM GCC
- Утилита Make
- OpenOCD для программирования
- STM32F4VET6U

### Процесс сборки

1. Клонируйте репозиторий с проектом:
```bash
git clone <repository-url>
cd <project-directory/deployment/stm32f4>
```

2. Настройте переменные окружения (при необходимости):
```bash
export ARM_GCC_PATH=/path/to/gcc-arm-none-eabi
export OPENOCD_PATH=/path/to/openocd
```

3. Соберите проект:
```bash
make all
```

4. Соберите и загрузите прошивку на устройство:
```bash
make program
```

Это выполнит следующие действия:
- Компиляция всех исходных файлов
- Линковка в ELF-файл
- Загрузка прошивки на устройство через OpenOCD
    - Верификация записанной прошивки
    - Сброс устройства для запуска программы

### Очистка проекта

Для очистки собранных файлов выполните:
```bash
make clean
```

## Подключение дисплея

Подключение дисплея ST7735S к STM32F4 Discovery Board происходит следующим образом:

| Пин дисплея | Пин STM32F4 | Назначение      |
|-------------|-------------|-----------------|
| VCC         | 3.3V        | Питание 3.3V    |
| GND         | GND         | Земля           |
| SCL         | PA5         | SPI1 SCK        |
| SDA         | PA7         | SPI1 MOSI       |
| RES         | PD2         | Сброс дисплея   |
| DC          | PD3         | Данные/Команда  |
| CS          | PD1         | Выбор чипа      |
| BLK         | 3.3V        | Подсветка       |
