# Документация драйвера дисплея ST7735S

## Обзор

Драйвер для управления дисплеем ST7735S через интерфейс SPI. Поддерживает основные графические примитивы и управление настройками дисплея.

## Функции

### ST7735S_RegisterBusIO

```c
int32_t ST7735S_RegisterBusIO(ST7735S_Object_t *pObj, ST7735S_IO_t *pIO);
```

**Назначение:** Регистрирует низкоуровневые функции ввода-вывода для работы с дисплеем.

**Параметры:**
- `pObj` - указатель на объект ST7735S
- `pIO` - указатель на структуру с функциями инициализации, записи регистров и передачи данных

**Возвращаемое значение:**
- `ST7735S_OK` - в случае успеха
- `ST7735S_ERROR` - в случае ошибки

---

### ST7735S_Init

```c
int32_t ST7735S_Init(ST7735S_Object_t *pObj, uint32_t ColorCoding, uint32_t Orientation);
```

**Назначение:** Инициализирует дисплей ST7735S.

**Параметры:**
- `pObj` - указатель на объект ST7735S
- `ColorCoding` - цветовой режим (например, RGB565)
  - `ST7735S_FORMAT_RBG444` - 12 бит на пиксель
  - `ST7735S_FORMAT_RBG565` - 16 бит на пиксель
  - `ST7735S_FORMAT_RBG666` - 18 бит на пиксель
- `Orientation` - ориентация дисплея:
  - `ST7735S_ORIENTATION_PORTRAIT` - Портретная ориентация
  - `ST7735S_ORIENTATION_PORTRAIT_ROT180` - Портретная ориентация, повернутая на 180°
  - `ST7735S_ORIENTATION_LANDSCAPE` - Альбомная ориентация
  - `ST7735S_ORIENTATION_LANDSCAPE_ROT180` - Альбомная ориентация, повернутая на 180°

**Возвращаемое значение:**
- `ST7735S_OK` - при успешной инициализации
- `ST7735S_ERROR` - в случае ошибки

## Пример использования

```c
// Инициализация дисплея
static ST7735S_Object_t Display;
ST7735S_IO_t io = {
    .Init = STM32F4_IO_SPI_Init,
    .DeInit = STM32F4_IO_SPI_DeInit,
    .WriteReg = STM32F4_IO_SPI_WriteDataReg,
    .SendData = STM32F4_IO_SPI_SendData,
    .Delay = STM32F4_IO_Delay_Func,
};

// Регистрация функций ввода-вывода
ST7735S_RegisterBusIO(&Display, &io);


// Инициализация дисплея
ST7735S_Init(&display, ST7735S_FORMAT_DEFAULT, ST7735S_ORIENTATION_LANDSCAPE);

// Рисование прямоугольника
ST7735S_FillRect(&display, 10, 10, 50, 30, 0xF800);
```
